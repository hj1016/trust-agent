|---|---|---|---|---|
| 단순 Hybrid vs Ontology-aware Retrieval | BM25 + dense vector k-NN + metadata filter + reranker | 같은 ES baseline + 경량 도메인 관계/structured metadata | 검색 정확도/관계 표현력/설명 가능성/복잡도/1인 범위/평가 가능성 | |
| 포맷별 parsing / OCR fallback 여부 | native parser + 공통 normalized document | 품질 미달/무 text layer에 한정한 OCR 후보 또는 수기 보류 | 실제 입력 포맷/구조 보존/숫자·시행일 정확성/비용/품질 임계값 | |
